# Distraction-Free YouTube 

A clean and distraction-free way to watch YouTube videos
without recommendations, comments, and other distractions.

# Features
- No recommended videos
- No comments section
- Clean minimal UI
- Categories: Coding, Gaming, Music

- HTML
